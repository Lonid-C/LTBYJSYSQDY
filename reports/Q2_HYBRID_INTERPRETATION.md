## 0. 一句话结论

**决策时序（何时锁定储能动作）是主效应，预测精度的提升是次效应。**
把"0:00 一次性锁定全天充放电"改为"日内逐槽因果执行"，在三种预测方法下一致地把总费用压低
**3.81%–5.00%**，并把紧急购电费用占比从 **6.81%–7.22%** 压到 **2.56%–3.43%**。
在此之上，H1-replan / H3 / H4 之间的差异 **≤0.50%**，且 Bootstrap 置信区间均跨 0，**不构成统计上可确立的改进**。

## 2. 四个必须区分的量（概念边界，不得混用）

论文与汇报中以下四个量含义不同，**不可互相替代**：

| 量 | 含义 | 本次是否有 | 出处 |
| --- | --- | --- | --- |
| **实际回测费用差** | 在同一信息约束下、用真实数据回放得到的可实现费用差 | **有** | `summary.csv` `total_cost` |
| **匹配终态的完美信息 Oracle 差距** | 事后已知全天真实净负荷、且终态 SOC 与实际匹配的确定性 LP 下界 | **有** | `matched_oracles.csv` |
| **VSS**（随机解价值） | 期望值问题解 vs 随机规划解，在同一概率测度下的期望差 | **无**（P5 暂停） | — |
| **EVPI**（完全信息价值） | wait-and-see 期望值 vs 随机规划最优值 | **无**（P5 暂停） | — |

两点必须明确：

1. `matched_oracles.csv` 的 `oracle_cost ≈ 12,230,400 元` 是**事后完美信息下界**，属于 hindsight 基准。
   它 **不等于** EVPI：EVPI 是"提前知道未来"在随机规划意义上的期望价值，需要在概率测度下求期望，本次未计算。
2. `oracle_dual_gap_relative ≈ 4.57e-16` 是 **HiGHS 求解器的数值对偶残差**，只说明 LP 收敛，**不是经济含义上的对偶间隙**，不得作为结论引用。

因此本次可以主张的是："因果执行把与完美信息下界的距离缩小了约四分之一"，**不能**主张任何 VSS/EVPI 数值。

## 4. 判定：0.1% 阈值与"优先简单模型"

按项目既定规则（近似同价阈值 0.1%，近似持平时优先简单模型）：

| 比较 | 费用差 | 是否超 0.1% | Bootstrap 支持 | 综合判定 |
| --- | ---: | :---: | :---: | --- |
| H0 → H1（因果执行） | −3.81% ~ −5.00% | 是 | 是（H0 显著更差） | **确立，主效应** |
| H2（点预测）→ 风险策略 | +3.01% ~ +12.63% | 是 | 是（H2 显著更差） | **确立，风险裕度必要** |
| H1-replan vs H3 | −0.02% ~ −0.50% | TeamA 未超；其余超 | **否（CI 跨 0）** | **不确立 → 视为持平** |

| H1-fixedQ vs H3 | +0.37% ~ +0.81% | 是 | 部分（Ridge later61 显著更差） | **H1-fixedQ 劣，排除** |

因此：**"分位数/条件分位数带来额外收益"这一说法在现有证据下不成立**；能成立的是"因果执行"和"风险裕度相对点预测"。

## 5. 推荐方案

综合七项准则（端到端费用、紧急购电风险、月度稳定性、Bootstrap、Oracle 差距、复杂度、决策时序合理性）：

| 准则 | H1-replan | H3 分位数 | H4 条件分位数 |
| --- | :---: | :---: | :---: |
| 全周期费用（3 种预测） | **最优** | 第 2–3 | 第 2（Ridge） |
| 紧急购电暴露 | **最低** | 高 25%–45% | 高 25%–45% |
| 11–12 月稳健性 | 中（TeamA 最优） | 优（ManualWeekly 最优） | **最优（Ridge）** |
| Bootstrap vs H3 | 持平 | — | 持平 |
| Oracle 后悔率 | **最低** | 中 | 低（Ridge） |
| 模型复杂度 | **低**（复用 SAA） | 高（α/ρ/窗口/平滑） | **最高**（+季节特征） |
| 决策时序合理性 | 合理 | 合理 | 合理 |

**推荐：以"因果执行"作为 Q2 的方法论主贡献；以 `H1-replan` 作为最终落地的推荐策略。**

理由：H1-replan 在三种预测方法下费用最低、紧急购电暴露最低、Oracle 后悔率最低、实现最简单（复用既有加权 SAA 代码），且与 H3/H4 的差异统计上不显著。

**H3/H4 的定位应调整为"风险感知变体 + 参数锚点验证"**，而非"更优策略"：
- 其独立价值在于 α 逐月选择收敛到 α\*=0.8，验证了紧急电价经济学；
- 其增量费用收益 ≤0.5% 且不显著，不宣称优越；
- 在 Ridge 预测下 H4 对 11–12 月略有改善（−0.31%），可作为稳健性脚注保留。

**若论文叙事必须突出分位数方法**，则应如实表述为："分位数风险净负荷与加权 SAA 在端到端费用上统计等价；前者以单场景形式复现了后者的对冲效果，并提供了 α\*=0.8 的可解释参数锚点。"

## 6. 局限（必须写入论文）

1. **参考计划仍以 `terminal = 6000 kWh` 求解**。所有 H1/H3/H4 的日前 LP 都以当日末 SOC 回到 6000 kWh 为约束生成参考轨迹，而实际 SOC 跨日连续（终态 6,038–6,192 kWh）。这构成计划层与执行层之间的内部不一致：计划系统性"多买"以回到 6000，实际却停在高位。已用 `inventory_adjusted_cost` 做过库存校正，校正量 <0.001%（如 Ridge H1-replan：13,667,441.21 → 13,667,412.36 元），**影响可忽略**，但机制应在论文中说明。
2. **`H1-replan` 的配置未参与调参**（固定 `rho = 0.5`、SAA 内部窗口 21 天、半衰期 14 天）。其"最优"是在未调参条件下的最优，这对 H1-replan 是不利的；换言之 H1-replan 的优势是稳健的下界。
3. **Oracle 为匹配终态的 hindsight 下界，不含跨日 SOC 条件的信息价值**，且不等于 EVPI/VSS。
4. **Bootstrap 为 7 日移动块**，对日内自相关未做额外建模；置信区间偏窄的可能性存在，但结论方向（跨 0）在 dev/later 两区间一致。
5. **α 锚点验证是单时槽近似**。α\*=0.8 的推导忽略 SOC 跨时槽耦合，数据落在 [0.74, 0.83] 只说明该近似在历史区间内可用，不构成一般性定理。
