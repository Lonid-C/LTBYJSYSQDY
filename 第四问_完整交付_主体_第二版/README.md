## 六条不能删的「模型解释边界与稳健性说明」（论文 4.6.5 节）

写进论文时请保留——这是本包相对其他方案的加分项。小节标题用
`4.6.5 模型解释边界与稳健性说明`，不要写成"诚实性条款第 N 条"这类审查清单式表达：

1. **参数标定与泛化边界**：两个"1 月训练更优、评价期回放更差"的候选解（Q4-2 放宽范围 +1.42%、Q4-3 超范围 +0.46%，均相对各自分支的 B0（α=0.60）基线），未采纳；shrink 范围 [0.55,1.30] / [0.30,1.60] 是人为设定的正则化约束而非理论边界；**参数取值**在评价期回放前冻结，但**参数范围与模型结构**曾结合历史回放修订，因此**不宣称独立盲测**
2. **复杂策略的适用边界**：Q4-2 的融合算法未能胜出，比分位法贵 25,286.65 元；结论只适用于本文数据与预算
3. **Q4-2 的补救决策结构**：Q4-2 **仍包含 recourse**——它没有日内增减购通道，但每个情景仍有独立的储能与应急变量；同时承认情景内使用完整路径求解带来的前视近似
4. **信息价值指标的命名边界**：不使用 VSS / EVPI 术语，也不下"电价预报投入性价比低"的结论
5. **结算口径敏感性**：1.5 倍条款按交付时段电价读为主口径；下单时刻读法按**有效配对**重算（72,144 对中 26.91% 满足 1.5p_release < p_delivery），作为口径敏感性并列；减购口径另有净额退款 vs 逐次分别计费的对照
6. **因果性与统计检验边界**：12 次因果性检查计划变动均 0.0 kWh，只支持被测试的日期与时点；均值检验的显著性不替代 CVaR 尾部结论
