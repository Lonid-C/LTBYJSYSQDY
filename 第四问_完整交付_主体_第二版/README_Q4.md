## 一句话结论

两个口径的答案不同，如实并列（历史前推 2025-02-01 — 12-31，334 天，库存校正费用，元）：

| | Q4-2（无日内增减购） | Q4-3（0/6/12/18） |
|---|---:|---:|
| 沿用第三问 α=0.60 的分位法 | 15,585,897.85 | 14,145,416.14 |
| **主策略** | **分位法 α=0.675：15,127,539.71（−2.94%）** | **HYBRID-4L：14,028,199.24（−0.83%）** |
| HYBRID-4L | 15,152,826.36（+0.17%，未胜出） | 即主策略 |
| 滚动视野完美信息对照（**不是下界**） | 12,841,236.28 | 12,830,984.55 |
| 全期完美信息真下界 | 12,782,823.86 | 12,782,827.41 |

Q4-2 的融合算法没打过标定后的分位法，照实报告。**但这不构成"随机规划在无日内调整场景下无效"的证明**：
Q4-2 每个情景仍有独立的充放电、库存与紧急购电变量，情景内前视近似依然存在；
把 `shrink` 固定为 1 是短训练窗口下减少自由度的**正则化选择**，不是结构性定理。

## 口径（全包统一）

- 计划与调整电量均按**交付时段实际电价** V[d,t]（附件 4）结算；增购 1.5×p，减购取消部分付 0.5×p 违约金。
- 减购采用**净额退款**：日末按最终有效购电量相对 0:00 基准计划一次性净额结清。
- 紧急购电 5×p；允许无成本弃电，不允许反向售电。
- 库存校正费用 = 现金费用 + v_E×(期初−期末)，v_E = 附件 1 最低分时电价 / η = 0.4125555556 元/kWh。
- 储能：12,000 kWh / 5,000 kW / η=0.9 / SOC ∈ [1200, 10800] kWh / 步长 10 分钟。
- 评价期 2025-02-01—12-31（334 天 / 48,096 段）；选参窗口**仅 2025 年 1 月**三块滚动验证。
- **不宣称独立盲测**：参数**取值**在评价期回放之前冻结，但模型结构与参数**范围**曾结合历史全年回放修订。评价期结果的定位是"同一历史样本上的回放稳定性比较"。
