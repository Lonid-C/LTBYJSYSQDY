# Q3 联合情景候选模型

令 eL=L-Lhat、eP=P-Phat。每条历史样本为同源的(eL[1:144],eP[1:144])。在每个发布时刻仅选择已完整揭示的历史视野，以历史通道标准差归一化，k-medoids保留12条配对代表路径，权重正比于簇大小的temper次幂。场景负荷与光伏分别为max(0,forecast+shrink*error)，净电量为(Ls-Ps)/6。

沿用HYBRID两阶段LP：共同合同决策、情景补救、线性电量平衡、SOC递推、容量与功率限制；未来补救在下一允许发布时刻前锁定。负荷和光伏只通过净负荷进入该LP，因此本次新增重点是配对误差诊断和联合聚类，而非增加两套独立供需约束。

实际结算为 C = Σ_t p_t[q_t^0 + 1.5 max(q_t-q_t^0,0) - 0.5 max(q_t^0-q_t,0) + 5z_t]。评价费用再加vE*(initial-final)。终端V的边际非增，V是凹函数，-V为凸成本。优化中的调整风险溢价沿用所选参数，不能与实际收费系数混淆。

负荷/光伏误差相关性的符号不预设；危险联合尾部用1月分位阈值定义并冻结。默认一次运行仅比较原净负荷情景与联合情景，固定所有已选参数、初始SOC和结算规则。输出费用变化不代表纯相关性贡献，亦不代表现实全局最优性差距。
