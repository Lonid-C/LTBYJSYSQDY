# CUMCM 2026 C 题：微网与外部电网电力调控策略

2026 年高教社杯全国大学生数学建模竞赛 C 题。本题围绕一个非孤岛式微网，在光伏本地消纳的经济性目标下，决定**每天何时购电、购多少电、何时充放电**，使小区负载得到满足的同时购电费用尽可能低。

题面共 4 问，四问的差别集中在电价口径、负载/光伏信息集和购电罚则上：

| 维度 | 问题 1 | 问题 2 | 问题 3 | 问题 4 |
| --- | --- | --- | --- | --- |
| 电价 | 每天相同（附件 1） | 每天相同（附件 1） | 每天相同（附件 1） | **逐日逐时波动（附件 4）** |
| 负载 / 光伏 | 每天相同 + 单日光伏预测 | 逐日变化（附件 2 实际值） | 附件 2 + **附件 3 整点预报** | 同问题 3 |
| 供 ≥ 需 | 硬约束 | 缺口按 **5 倍电价**紧急购电 | 同问题 2 + **调整购电双向罚则** | 同问题 2 / 3 |
| 储能首末 | **0:00 与 24:00 储电量相等** | 无此要求 | 无此要求 | 无此要求 |
| 决策时刻 | 每天 0:00 | 每天 0:00 | **0:00 / 6:00 / 12:00 / 18:00** | 同问题 2 / 3 |
| 交付文件 | `result1.xlsx` | `result2.xlsx` | `result3.xlsx` | `result4-2.xlsx`、`result4-3.xlsx` |

储能设备参数（附录 1，全题共用）：最大容量 12 000 kWh，最大充放电功率 5 000 kW，2025-01-01 0:00 电量为 6 000 kWh，运行区间 1 200–10 800 kWh，充放电效率均 90%。

## 四、时间网格口径（关键，勿改）

- 模型采用**自然日网格 0:00–24:00，共 144 个 10 分钟槽**，槽 \(t=[10t,\,10(t+1))\) 分钟。
- 附件 1 / 2 / 4 的时间标签为 `0:10` → `24:00`，是槽的**右端点**。
- 附件 5 模板（`result1.xlsx`、`result2.xlsx`）的区间名是 `0:10-0:20` → `24:00-24:10`，**整体后移一格，属模板命名瑕疵**。
- **正确填表方式是「位置对应」**：模板第 \(k\) 个数据格 ↔ 附件第 \(k\) 列 ↔ 模型第 \(k\) 槽。不改模板表头。
- 论文表 1 / 表 2 的区间名必须与交付表一致，否则按标签逐格核对会被判错位。

## 五、问题 3 应该基于什么来做

### 5.1 结论：基于 `code/q2_v32/q2_final.py`

它已经是问题 2 的最小可运行生产版——比 `q2_v31/q2_terminal_ablation.py` 更干净（没有消融脚手架），但完整保留了问题 3 需要的三样核心资产：

| 复用对象 | 在 Q3 中的作用 |
| --- | --- |
| `Experiment.scenarios()` / `solve()` | 场景构造与风险中性两阶段 SAA，直接作为 0:00 计划层 |
| `learn_value_bank()` / `build_value_banks()` / `bank_for_date()` | 17 点对偶终端库存价值，避免跨日边界效应 |
| `dispatch.execute_day()` | H1 逐时因果执行器，产出实际充放电与紧急购电 |
| `write_result2()` / `audit_result2()` | **改造成 `write_result3()`**：多出「调整购电量」表，其余三表结构相同 |

**不要基于** `q2_v31`（消融脚手架）、`q2_hybrid.py`（早期路线，含已被取代的每日 SOC 回 6000 假设）、`q2_v2`（题意边界扩展）。

### 5.2 问题 3 相对问题 2 的三个新增点

**① 附件 3 的整点预报要降尺度，且必须先统一口径。**
附件 3 是**小时分辨率**（每天 0/6/12/18 各发布一次未来 24 小时整点预报），模型需要 144 个 10 分钟槽，题目没有规定降尺度方式，这是必须自行固定的自由度。已知的映射是 `预报 k 小时 ↔ hour = 发布时刻 + (k−1)`，跨日顺延。

⚠️ 关键陷阱：附件 3 是**整点瞬时功率**，而附件 2 是 10 分钟实测值。直接用小时均值对标会得到 **MAE ≈ 780.7 kW、偏差 +690.3 kW**，其中偏差主要来自「瞬时 vs 均值」的**口径差**而非预报系统性高估。**不先统一口径，会把口径差误判成预报偏差**，退化为一整套错误的误差模型。

**② 计划 / 调整 / 紧急三层结构，价格体系比问题 2 复杂。**

题面原文规定的结算规则：

| 电量 | 单价 |
| --- | --- |
| 计划购电量 | 交易时刻电价 × 1 |
| 计划量高于调整量的部分（计划了却没买） | × 0.5（违约罚金） |
| 调整量高于计划量的超出部分 | × 1.5 |
| 最终实际缺口紧急购电 | × 5 |

记计划量为 \(q^{\rm plan}\)、调整量为 \(q^{\rm adj}\)、时槽电价为 \(p\)，按题面分段规则展开后可以归约为

$$
\text{购电费}=p\,q^{\rm adj}+0.5\,p\,\bigl|q^{\rm adj}-q^{\rm plan}\bigr| .
$$

也就是说：**调整量始终按正常电价结算，偏离计划的部分另按 0.5 倍电价计罚，且罚金与偏离方向无关**（上式两个方向代数上恒等）。

这个对称性有两个直接后果，都是 Q3 建模的抓手：

- **计划层不直接决定购电量**，只通过 \(0.5p|q^{\rm adj}-q^{\rm plan}|\) 这一项起作用，因此 \(q^{\rm plan}\) 与 \(q^{\rm adj}\) 是嵌套关系，不能简单地把 \(q^{\rm plan}\) 当作被解释变量。
- 目标函数中只出现绝对值，**整体仍是分段线性**，用辅助变量做双向线性化后依然可以用 LP 求解，不需要引入非线性或启发式搜索。

建议对「30%/50%/100% 偏离罚金」与「1.0/1.5/2.0 倍上调价」各做一档敏感性，量化计划层的价值。

**③ 题面明确要求回答一个附加问题**：「请分析是否需要引入其他时刻的预报制定调整购电策略」。这要求做**消融对照**，至少两档：只用 0:00 预报（等价于问题 2）+ 加 6/12/18 调整层，用费用差回答。

### 5.3 需要先定的建模分叉

| 分叉点 | 选项 | 建议 |
| --- | --- | --- |
| 附件 3 降尺度方式 | 线性插值 / 保形插值 / 按日内形状分配 | 先固定一种并在论文中声明，另做敏感性 |
| 调整层范围 | 只调购电量 / 购电量+储能一起重规划 | **建议两版都跑**，用费用差同时回答题面附加问题 |
| 调整层的误差模型 | 用附件 3 预报 vs 附件 2 实际光伏的历史误差，按发布时刻（0/6/12/18）分别建模 | 分时刻建模，因为预报精度随提前期显著变化 |

## 七、复现方式

```bash

# 2. 创建会话并上传

colab exec     -s cumcm-2026-last-dance -f code/q2_v32/colab_launch_v32.py
colab download -s cumcm-2026-last-dance /content/q2_v32_outputs.tar.gz tmp/q2_v32_outputs.tar.gz

# 4. 停止会话，不要留空闲 VM
colab stop -s cumcm-2026-last-dance
```
