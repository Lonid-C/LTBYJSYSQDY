| 项 | 设定 |

| 岭正则 | 手工设定 |
| 额外惩罚项 | 含调整量惩罚、SOC 惩罚、库存保留系数 |

**关键结果**

| 指标 | 数值 |
|---|---|
| 2—12 月总购电费（全更新） | 13,440,139.28 元 |
| 不更新对照 | 14,559,779.48 元 |
| 节约 | 1,119,640.20 元（7.690%） |
| **累计减购量** | **0 kWh** |
| 累计增购量 | 351,742 kWh |
| 紧急购电量 | 41,358 kWh |
| 2 月 1 日初始库存 | 7,291.2 kWh |

**暴露出的结构性问题**

1. **减购被数学上严格支配。** 旧口径下由 100 减到 80 需付 `110p_t`，高于不调整的 `100p_t`，因此模型必然输出减购量 = 0，题目专门设置的「50% 违约价格」形同虚设。
2. **风险分位缺少理论来源**，0.80/0.70 这类取值看起来像人工试出来的。
3. **终端条件 `E₂₄ = 0.5B` 没有数据来源**，等于人为规定「SOC 越接近 50% 越好」。
4. **叠加了无来源的惩罚项**（调整量惩罚、SOC 惩罚），与题目已显式给出的 0.5/1.5/5 倍价格机制重复计价。
5. 充放电工作表「时刻」列把第二个 4 小时块误标为 24:00。

## V1 — 改进版第一轮

**触发依据**：《第三问模型改进建议：结算口径与参数来源说明》。

**修改目标**：修正结算口径的结构性缺陷，并把每个参数的来源讲清楚（题目给定 / 理论推导 / 数据校准 / 数值设定四级）。

### 1.1 结算口径重构（核心）

主结算公式改为相对 0:00 基准计划的**净额退款式**结算：

$$C=\sum_t\left[p_tq_t^0+1.5p_t(q_t-q_t^0)^+-0.5p_t(q_t^0-q_t)^++5p_tz_t\right].$$

即：取消部分只承担 50% 的违约成本（退回 50%），而不是在照付原费之外再罚 50%。

| 项 | V0 | V1 |
|---|---|---|
| 减购的经济含义 | 取消部分 = 原费 + 0.5 倍罚金 = 1.5 倍 | 取消部分只承担 0.5 倍违约成本 |
| 减购行为 | 恒为 0（被严格支配） | 715,987 kWh（真实进入优化） |
| 实现 | — | `settle_coef()`：净额口径系数 −b，旧口径 +b |

**为什么必须改**：只有改成净额退款，题目给出的 0.5 倍违约价格才具有决策意义，模型才能产生真实的减购行为。

### 1.2 交易电价与净额结算

| 修改 | 实现 |
|---|---|
| 交易电价统一取**该电量所属交付时段**的分时电价 | 全部按区间索引 `price[t]`，不取下单时刻价格，消除下单时点套利 |
| 多次日内调整按相对 0:00 计划的**净额结算一次** | 加约束 `q − u + v = q⁰`，只对最终净额计费（100→120→105 只按 105−100=5 结算） |

### 1.3 风险分位给出理论锚点与有限校准区间

推导无储能局部单阶段边际成本模型下的临界分位，作为**经济理论基准分位**：

$$\alpha_0^{\text{base}}=1-\frac{1}{m}=0.80,\qquad \alpha_h^{\text{base}}=1-\frac{a}{m}=1-\frac{1.5}{5}=0.70.$$

校准只在理论中心邻域内进行（V1 为 $\alpha_0\in\{0.60,\dots,0.90\}$、$\alpha_h\in\{0.50,\dots,0.80\}$，共 49 组）。

### 1.4 用经济终端库存价值取代固定 50% SOC

取消硬约束 `E₂₄ = 0.5B`，改为目标函数加入 $-v_E E_D$，其中 $v_E=p_{\min}/\eta_c$ 表示「未来重新补回 1 kWh 电池内部能量所需的最低替代购电成本」。参数来源明确，不是经验参数。

### 1.5 滚动 24 小时视野

每个发布时刻（0:00 / 6:00 / 12:00 / 18:00）优化其后 24 小时，只执行紧随的 6 小时，其余在下次发布时重新求解。

### 1.6 剔除无来源惩罚项

$$\lambda_\Delta=0,\qquad \lambda_{SOC}=0,\qquad \text{reserve}=0.$$

仅保留 $\varepsilon=10^{-7}$ 作为数值退化惩罚（在成本相同的多个最优解中选吞吐更小的解），并验证 $10^{-8}/10^{-6}$ 不改变经济结果。

### 1.7 时间窗口参数来源说明

28 天 = 4 周、14 天 = 2 周、1 小时 = 6 个 10 分钟段、6 小时 = 相邻预测发布间隔。

1. 第一轮最优解 **α₀=0.60 恰好落在搜索区间下边界**，只能说明「已测候选中 0.60 最好」，不能说明邻域已覆盖完整。

## V2 — 改进版第二轮

**触发依据**：《第三问改进版：最终修正清单》（P0/P1/P2 三级）。

**修改目标**：修复选参边界截断、消除报告与代码矛盾、重新定位理论分位的论文地位，并把「唯一最优」的表述弱化为「稳定低成本邻域」。

### 2.1 P0-1 扩大风险分位搜索范围 + 边界自动延展

- 候选集合扩为 $\alpha_0\in\{0.45,0.50,\dots,0.90\}$（10 档）× $\alpha_h\in\{0.50,\dots,0.80\}$（7 档）= **70 组**。
- `calibrate()` 新增**边界自动延展**：若最优解仍落在边界，就继续 ±0.05 扩展重测，直至最优位于已测试区域内部。
- 结果：最优 (α₀, αₕ) = **(0.60, 0.60)** 已位于区域内部，`checks.json` 的 `alpha0_interior` / `alpha_update_interior` 均为 `true`。
- 证据：`results/calibration.csv`、`results/calibration_grid_extension.json`。

### 2.2 P0-2 删除与代码矛盾的描述

删除「没有使用跨日预测优化」的旧表述，改写为与代码一致的描述：各发布时刻采用 **24 小时滚动视野**，跨午夜窗口使用**当前决策时点已发布的**次日预测部分。同时补充模型边界声明：**仍是确定性滚动优化，不是完整多阶段随机规划**。

### 2.3 P0-3 术语修正：经济理论基准分位

全库统一改称 **「经济理论基准分位」（无储能局部单阶段条件下的理论临界分位）**，明确仅作为完整储能滚动优化模型的**理论锚点**，不再称完整模型的理论最优值。直接使用该锚点而不校准的费用为 13,478,826.78 元（相对主口径 +0.692%）。

### 2.4 P1-4/P1-5 弱化唯一最优 + 滚动多窗口时序验证

- 新增 `rolling_validation()`：在 3 个评价期之前的连续窗口上回放候选参数，按三个验证区块的**平均库存校正成本**选参。
- 折次结构：第 1 折 训练 1/1–1/7 → 验证 1/8–1/15；第 2 折 训练扩展至 1/15 → 验证 1/16–1/23；第 3 折 训练扩展至 1/23 → 验证 1/24–1/31。
- 主口径即由该规则选出的 (0.60, 0.60)；单窗口规则选出的 (0.60, 0.55) 结果 **+0.320%**，作为对照并列报告。
- 报告措辞改为「风险参数**邻域内形成稳定低成本区域**」，不再断言某点唯一最优。
- 证据：`results/rolling_validation.csv`、`parameters.json:selection.folds`。

### 2.5 P1-6/P1-7 岭正则系数归类为预测超参数并按精度选择

- 归类为**四级：预测子模型工程超参数**，明确其**无经济含义**，不赋予不存在的业务解释。
- 用 `select_ridge()` 按**日间负荷预测精度**选择，而不是按账单：在评价期之前的窗口上选 RMSE 最小者。
- 得到 $\lambda_{\text{slope}}=10^{6}$、$\lambda_{\text{weekday}}=0.00625$。
- 两类参数彻底分开：**预测模型参数按预测准确性选，风险决策参数按最终经济成本选**。
- 如实说明：精度准则把趋势项正则推到上限（等价于取消局部线性趋势项），说明该窗口内局部趋势对预测精度无正贡献。

### 2.6 P2-9 新增逐次调整结算对照

新增 `settlements='stepwise'`（基准改为上一次有效计划，逐次计费）。三种结算解释并列对比：

| 结算解释 | 总费 / 元 | 累计减购 / kWh | 相对主口径 |
|---|---:|---:|---:|
| 主口径：净额退款结算 | 13,386,086.28 | 715,987 | 0.000% |
| 旧解释：原费照付＋0.5 倍罚金 | 13,448,630.15 | 0 | +0.467% |
| 逐次调整结算 | 13,555,574.64 | 958,315 | +1.266% |

核心结论对结算解释不敏感：不更新策略不产生任何调整，三种解释下费用完全相同。

### 2.7 P2-11/P2-12 参数邻域稳定性

对全部 70 个风险参数组合在评价期逐一回放：**100% 的参数组合下「6/12/18 全更新」仍优于不更新**，最低成本 0.2% 邻域占 14.3%。新增 `figures/参数邻域稳定性.*` 与 `results/stability_map.csv`。

## 7. 迭代逻辑链

四个版本共同落实了这条从经济机制到样本外验证的完整链路：

$$\text{题目经济机制}\ \rightarrow\ \text{理论参数锚点}\ \rightarrow\ \text{严格历史校准}\ \rightarrow\ \text{24h 滚动 MPC}\ \rightarrow\ \text{样本外经济评价}\ \rightarrow\ \text{结构敏感性验证}$$

- **V0 → V1**：修正结算口径（让 0.5 倍违约价格真正起作用）、补齐参数来源（四级参数体系）。
- **V1 → V2**：修复选参边界截断、消除报告与代码矛盾、重新定位理论分位、把「唯一最优」改为「稳定低成本邻域」。
- **V2 → V3**：把方法学细节（rolling-origin CV、扩展窗口折次）与清单推荐表述**逐条对齐**，不改变数值。
