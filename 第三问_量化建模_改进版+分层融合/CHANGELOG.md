## V4.0 — 改进版第四轮（当前）：多方法对比扩展

> **主模型数值不变**（α₀=0.60, αₕ=0.60；全更新 13,386,086.28 元）。本轮是在主模型之外**新增一整套替代方法的对比实验**，回答「遗传算法能否用于本题、还有什么别的方法」。

**新增程序**
- `code/method_comparison.py`：多方法分层对比实验框架。复用 `q3` 的 `Bank`／`execute`／结算口径，保证所有方法与 LP 基准**同口径可比**。
- `code/method_report.py`：方法对比图表（3 张）与 `reports/方法对比报告.md`。

**新增方法**
- **DP**：以 SOC 为状态、时段为阶段的动态规划（`dp_solve_clean`，后向值函数 + 精确离网前向传递）。网格 40/80/160 三档。
- **规则型阈值策略**：6 参数可解释规则（电价分位上/下界、SOC 上/下界、充/放速率）＋手工参数版。
- **GA**：① 直接编码 144 维购电计划（对照失败案例）② **NSGA-II 优化 6 个规则参数**（真正有效的用法）。
- **风险分位谱**：α₀ ∈ {0.45…0.95} 七点，代表鲁棒／保守度思想，提供成本—尾部风险权衡。

**三层对比结构**
- **L1 单阶段最优性**（10 个样本日，对照 LP 全局最优）：DP(160) 平均间隙 0.530%、DP(80) 1.007%、DP(40) 2.167%；**GA 直接编码 144 维平均差 20.31%（最差 41.51%）**；手工规则 48.99%。
- **L2 全年策略回测**：LP 13,386,086 元 → DP +0.914%、GA 调参规则 +12.255%、手工规则 +59.080%、LP 不更新 +11.050%、规则不更新 +18.831%。
- **L3 多目标**：成本—寿命 Pareto（NSGA-II，11 个前沿点，等效循环 1.1～8.3 次）；成本—风险谱（α₀=0.60 处 CVaR95 最低 63,668 元，两端均变差）。

**核心结论**
- 主问题是连续线性规划，LP 已有全局最优；DP 独立验证其最优性（间隙随网格 O(1/N) 单调收敛，紧急电量恒为 0）。
- **GA 不适用于直接编码 144 维决策变量**，但适用于低维策略参数寻优与多目标 Pareto。
- 报告已写入七维评分矩阵与「各方法该放在论文的哪个位置」的定位建议。

## V1.0 — 改进版第一轮

> 依据《第三问模型改进建议：结算口径与参数来源说明》。

**结算口径重构（核心）**
- 主公式改为净额退款结算：`C = Σ[p·q⁰ + 1.5p(q−q⁰)⁺ − 0.5p(q⁰−q)⁺ + 5p·z]`，取消部分只承担 50% 违约成本。
- 修复「减购被严格支配、恒为 0」的结构性问题：累计减购 0 → **735,114 kWh**，题目设置的 0.5 倍违约价格恢复决策意义。
- 交易电价统一取**交付时段**分时电价；多次调整按相对 0:00 基准计划的**净额结算一次**（约束 `q−u+v=q⁰`）。

**参数来源重构**
- 风险分位给出经济理论锚点：α₀=1−1/m=0.80、αₕ=1−a/m=0.70；校准仅在理论中心邻域内进行。
- 取消人工硬约束 `E₂₄=0.5B`，改用**经济终端库存价值** −v_E·E_D（v_E=p_min/η_c）。
- 采用**滚动 24 小时视野**：每发布时刻优化 24h、只执行 6h。
- 剔除无来源惩罚项：λ_Δ=0、无 SOC 惩罚、库存保留系数=0；仅保留 ε=10⁻⁷ 数值退化惩罚。
- 时间窗口来源说明：28 天=4 周、14 天=2 周、1 小时=6 个 10 分钟段、6 小时=相邻发布间隔。

**结果**：总费 13,440,139.28 → 13,435,399.87 元；节约 7.690% → **10.250%**。

## V0.0 — 原版（基线）

- 结算口径：原计划费用照付，减购另加 0.5 倍罚金 → 减购恒为 0。
- 优化视野：仅到当日 24:00。
- 终端条件：硬约束 E₂₄=0.5B。
- 风险分位：直接校准 50 组，无理论来源；1/15—31 单窗口选参；岭正则手工设定；含无来源的调整量惩罚与 SOC 惩罚。
- 结果：总费 13,440,139.28 元，节约 1,119,640.20 元（7.690%），累计减购 0 kWh。
