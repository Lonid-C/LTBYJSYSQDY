# 两套「融合方案」的对比：HYBRID-4L vs 最终融合方案（前瞻采购版）

对比对象：

- **本方案 HYBRID-4L**：建在《第三问量化建模（改进版）》之上，见 `reports/分层融合算法报告.md`；
- **最终融合方案**：用户提供的 `第三问_量化修订版/融合算法/最终方案`，建在《第三问量化修订版》之上。

结论先写：**两者的账单差了 2,131,738 元（16%），但其中约 14.9 个百分点来自一条合同条款的
不同读法，不是来自算法。** 只比算法的话，两者的增益是同一量级：最终融合方案 −0.67%，
本方案 −0.585%，都在半个百分点上下。

---

## 1  为什么账单不能直接比

两个包的物理模型、附件数据、评价期（2/1—12/31，334 天）都一样，但**结算口径有三处根本不同**：

| 口径项 | 本方案 HYBRID-4L（沿用改进版） | 最终融合方案（修订版） | 影响 |
|---|---|---|---|
| **调整电量按哪个价计费** | **交付时段电价** `price[t]` | **发布时刻电价** `price[6h-1]`（`pricing='issue'`，且 `left_price=True`） | 决定性 |
| 减购如何结算 | 净额退款：取消部分只承担 50% 违约成本（`net_refund`） | 原费照付＋另加 50% 罚金（`refund=false`） | 后者下减购被严格支配为 0（`down_kwh=0`） |
| 视野末端库存 | 经济库存价值 $-v_E E_D$（本方案进一步升级为分段线性 $V(E)$） | 固定日末 SOC 目标 `target=0.64` | 次要 |
| 是否主动前瞻采购 | 无 | `anticipatory=True`：日前 LP 主动把采购留给更便宜的发布时刻 | 只有在「发布时刻电价」下才有意义 |

第一条是要害。题目原文是

> 调整购电量高于计划购电量的部分，超出部分的电价是**交易时刻电价**的 1.5 倍。

「交易时刻」可以读成**下单的那一刻**，也可以读成**该电量交付的那个时段**。两种读法的后果完全不同。

### 1.1 「发布时刻电价」这条读法会把罚金变成折扣

附件 1 的分时电价在本题里从 0.3713 到 1.3952 元/kWh。三个日内发布时刻的电价是

| 发布时刻 | 该时刻电价（左端） | ×1.5 后的「违约增购价」 |
|---|---|---|
| 6:00 | 0.9099 | 1.3649 |
| **12:00** | **0.4432** | **0.6648** |
| 18:00 | 1.2313 | 1.8470 |

也就是说，**在 12:00 下一笔"超计划增购"，单价 0.6648 元/kWh，比全年 57.6% 的交付时段电价都便宜（137 个电价档里有 82 档高于它）**，
比晚高峰 1.2561 元/kWh 的正常交付电价便宜 47%。于是模型的最优解必然是：

> 0:00 的计划**故意少买**，把负荷留到 12:00 用"违约增购"这个通道去买。

这正是最终融合方案里看到的结构——全年增购 **6,500,836 kWh**（约占全年用电的三分之一），
午夜计划费从 1,274 万元掉到 635 万元，而"逐次补购费"涨到 440 万元。

**1.5 倍的惩罚条款被用成了主要采购渠道**，这与条款"惩罚偏离"的意图相反。

### 1.2 数值上分离这条口径的贡献

最终融合方案自己的 `layer_attribution.csv` 已经把两件事分开了（现金费用，元）：

| 层组合 | 现金费用 | 相对该包基线 |
|---|---|---|
| 原参数 ＋ 无前瞻（= 修订基线） | 13,438,310.55 | 0.00% |
| **DE 精修 ＋ 无前瞻** | **13,348,203.81** | **−0.670%** ← 算法贡献 |
| **原参数 ＋ 前瞻** | **11,441,131.39** | **−14.861%** ← 口径贡献 |
| DE 精修 ＋ 前瞻（最终交付） | 11,176,156.92 | −16.834% |

再看该包自己在**交付时段电价**下重算的结构变体（`structure.csv`，现金费用）：

| 结构变体 | 现金费用 |
|---|---|
| 交付电价 ＋ 前瞻采购 | 13,579,455.19 |
| 交付电价 ＋ 无前瞻 | 13,608,533.81 |

**把计价改回交付时段电价，16.8% 的节约立刻从 226 万元缩到 2.9 万元（0.21%）。**
所以那 16.8% 的绝大部分是口径，不是优化。

## 2  只比算法：两者站在同一起跑线上的增益

| | 最终融合方案 | 本方案 HYBRID-4L |
|---|---|---|
| 所在基线 | 修订基线 13,438,310.55 元（现金） | 改进版基线 13,386,086.28 元（现金）／13,386,165.04 元（库存校正） |
| 最优结果 | 13,348,203.81 元（DE 精修＋无前瞻） | 13,310,698.98 元（现金）／**13,307,895.35 元（库存校正）** |
| **算法增益** | **−0.670%**（现金口径） | **−0.563%**（现金口径）／**−0.585%**（库存校正口径） |
| 增益是否显著 | 该包未报告显著性 | 配对 t 检验 $p=0.0044$，Wilcoxon $p=1.2\times10^{-10}$，216/334 天更省 |
| 风险指标是否同向改善 | 未单独报告 | 是：日 CVaR95 63,667.8 → 62,961.2 元，最差单日 68,827.7 → 68,195.2 元，紧急电量 65,262 → 54,734 kWh |

**两者的算法增益是同一量级（半个百分点上下）。** 这本身是个值得写进论文的结论：
在一个已经调好的滚动 LP 之上，任何元启发式能榨出来的空间都只有 0.5%—1%；
凡是宣称两位数节约的，基本都来自**口径或结构的改变**，应该单独归因。

## 3  两者的"融合"融的是不一样的东西

| | 最终融合方案 | 本方案 HYBRID-4L |
|---|---|---|
| 被搜索的对象 | 7 维策略向量：$\alpha_0,\alpha_6,\alpha_{12},\alpha_{18}$、`reserve`、`target`、`load_blend` | 5 维策略向量：情景权重温度、残差缩放、终端价值缩放、调整接受门槛、再调整期权溢价 |
| 搜索算法 | 差分进化 DE ＋ 有预算的随机搜索（作为对照）＋ 坐标模式搜索精修 | GA / DE / SA 同预算三选一 ＋ Nelder-Mead 精修（memetic） |
| 规划内核 | 确定性滚动 LP，用**分位数**把随机性确定化 | **两阶段情景随机 LP**：把 5 倍紧急、1.5 倍增购、0.5 倍违约同时写进规划目标 |
| 情景处理 | 无（单条分位路径） | 历史残差路径 ＋ **k-medoids 场景削减**（带权，保留时段相关性） |
| 非预期性约束 | 无显式建模 | 有：视野前 6 小时锁定不可再调，其后允许情景相关的再调整 |
| DP 的角色 | 作为电池价值执行层，**实测变差**（13,548,110 vs 13,438,898），最终权重置 0 不用 | 作为**终端价值函数的拟合手段**（一次 Bellman 回代 → 分段线性凸 $V(E)$，可直接嵌入 LP） |
| 多目标 | 无 | NSGA-II（结果：前沿退化成一点，说明本题不存在真实的成本—CVaR 权衡，已如实报告） |
| 调参窗口 | 1 月 15—31 日（`refine.py` 注明其 1 月分数不是留出验证） | 1 月三个滚动验证块 1/8—1/15、1/16—1/23、1/24—1/31，取平均，评价期完全留出 |

一句话概括差别：

- **最终融合方案**把力气放在**把分位数策略的参数调到最好**，再叠加一条口径上的采购通道；
- **本方案**把力气放在**换掉分位数这个启发式本身**——让 LP 从成本结构里解出"买多少"，
  元启发式只负责那几个 LP 写不进去的非凸参数。

两条路线**不冲突**：情景随机规划层与"交易时刻电价"的读法是正交的。如果采用发布时刻电价的读法，
把本方案的情景层套上去，理论上还能在 11.18M 之上继续改善（因为它会对这条采购通道做风险对冲，
而不是按单一分位去用）。需要的话可以再跑一版。

## 4  对论文写法的建议

1. **主口径建议用交付时段电价。** 1.5 倍条款在中文里是"违约加价"，如果按发布时刻计价会让它在
   12:00 变成比正常电价便宜 47% 的折扣，与条款意图相反；评委很可能按"钻条款空子"来看待。
2. **如果要保留 16.8% 这个数字，务必把它放在"口径敏感性"一节，并明确写出归因**
   （口径 −14.9%、算法 −0.7%）。最终融合方案的 `layer_attribution.csv` 已经做了这件事，
   这是该包的优点，论文里不要把它藏起来。
3. **两套方案可以并列进论文**：一条是"换求解范式"（确定性分位 → 两阶段随机规划），
   一条是"条款读法敏感性"。前者是建模贡献，后者是稳健性讨论，性质不同，不要混在一张表里比大小。
4. **显著性要报。** 半个百分点的改善必须配上配对检验，否则很难说服评委它不是噪声。
