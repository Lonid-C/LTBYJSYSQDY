# Q4 最终稳健性增强补充（2026-09-13）

本目录是 `../第四问_完整交付_主体_第二版/` 的最终补充实验，只处理三项问题：Q4-3 的 CVaR95 区间跨 0、因果性检查覆盖较少、泛化证据不够强。原 Q4-3 六个策略参数保持冻结，本轮不重新搜参。

## 最终报告口径

- **经济主策略**：沿用第二版 H3 HYBRID-4L，库存校正费用 14,028,199.24 元，相对 Q4-3 B0 节约 117,216.90 元（0.829%）。
- **风险增强策略**：在随机 LP 目标中加入权重 `rho=0.25` 的 CVaR95 项。库存校正费用 14,043,235.26 元，相对 B0 仍节约 102,180.88 元；CVaR95 为 74,092.06 元，相对 B0 降低 1,293.22 元（1.715%）。
- **显著性边界**：`rho=0.25` 的 7/14/28 日块 Bootstrap 95% 区间分别为 `[-2782.92, 30.57]`、`[-2940.46, 225.57]`、`[-2957.99, 613.88]` 元。证据比旧 H3 明显增强，但三档仍跨 0，因此不宣称“统计显著降低尾部风险”。
- **因果性**：56 个代表日、4 个发布时点，共 224 个决策状态全部通过，扰动尚未释放的未来信息后计划最大变动为 0.0 kWh。
- **时间泛化**：`rho=0.15` 在四个时间块均保持正节约；`rho=0.25` 的 2—4 月块出现轻微费用退化，因此作为风险偏好备选，不取代经济主策略。
